# Quick Start Guide - F-Stack HTTP Reverse Proxy

This guide will help you quickly set up and test the F-Stack HTTP reverse proxy.

## Prerequisites

- F-Stack already installed and configured
- DPDK set up with network card bound
- Python 3 installed (for test backend server)
- Root access

## Step-by-Step Setup

### Step 1: Build the Proxy

```bash
cd /path/to/f-stack/example
make
```

This creates `helloworld_proxy` executable.

### Step 2: Start Backend HTTP Server

Open a terminal and run:

```bash
cd /path/to/f-stack/example
python3 backend_server.py
```

You should see:
```
Backend HTTP Server running on http://127.0.0.1:8080
This server will handle requests forwarded from the F-Stack proxy
Press Ctrl+C to stop
```

Leave this running.

### Step 3: Configure F-Stack

Make sure your F-Stack configuration file (`/etc/f-stack.conf` or local `config.ini`) is properly set up:

```ini
[dpdk]
lcore_mask=1
channel=4
promiscuous=1
nb_ports=1
portmask=1

[port0]
addr=192.168.1.100      # Your network IP
netmask=255.255.255.0
gateway=192.168.1.1
```

### Step 4: Start F-Stack Proxy

Open another terminal and run:

```bash
cd /path/to/f-stack/example
sudo ./helloworld_proxy -c /etc/f-stack.conf
```

The proxy will start and listen on port 80 of the configured IP address.

### Step 5: Test the Proxy

From another machine (or same machine if you have a management interface):

```bash
# Using curl
curl http://192.168.1.100/

# Or use wget
wget http://192.168.1.100/ -O -

# Or open in a web browser
firefox http://192.168.1.100/
```

You should see a colorful HTML page generated by the backend server, confirming the proxy is working!

## Architecture

```
Client → [Network Card] → F-Stack Proxy (port 80) → Backend (127.0.0.1:8080)
                                ↓
                          Response back to Client
```

## Customization

### Change Backend Port

Edit `example/main_proxy.c` and modify:

```c
#define BACKEND_PORT 8080  // Change to your backend port
```

Then rebuild:
```bash
make clean
make
```

### Use Your Own Backend

Replace the Python test server with any HTTP service listening on 127.0.0.1:

**Node.js:**
```bash
npx http-server -p 8080 -a 127.0.0.1
```

**Python SimpleHTTPServer:**
```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

**Nginx:** Configure it to listen on 127.0.0.1:8080

**Any application:** Just make sure it listens on 127.0.0.1:8080

## Troubleshooting

### Proxy won't start
- Check you're running as root: `sudo ./helloworld_proxy ...`
- Verify F-Stack config path is correct
- Make sure network card is bound to DPDK: `dpdk-devbind.py --status`

### Can't connect from client
- Check firewall rules
- Verify the IP address in F-Stack config is correct
- Make sure the network card is on the same network as the client

### Backend connection fails
- Ensure backend server is running: `netstat -tln | grep 8080`
- Check it's listening on 127.0.0.1, not just localhost
- Verify `BACKEND_PORT` matches your backend

### No response or timeout
- Check backend server logs for errors
- Enable DEBUG logging in F-Stack config
- Monitor both terminals for error messages

## Performance Tips

1. **Multi-core**: Use multiple F-Stack processes for better CPU utilization
2. **Buffer size**: Increase `BUFFER_SIZE` in main_proxy.c for larger requests/responses
3. **Connections**: Increase `MAX_CONNECTIONS` for more concurrent clients
4. **Backend**: Ensure your backend server is optimized and can handle the load
